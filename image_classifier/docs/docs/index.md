# Classificador de imagens CIFAR-10

Este projeto treina uma rede neural convolucional com TensorFlow/Keras para classificar imagens da base CIFAR-10 em dez categorias.

O fluxo principal carrega e normaliza os dados, treina a CNN, avalia o resultado no conjunto de teste e salva o modelo em `models/cifar10_cnn.keras`. As instruções de instalação, comandos e arquitetura estão no README do projeto.
